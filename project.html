Smart RFID Car Parking System

This mobile app was developed specifically for TAR UMT’s Block K parking area to modernize vehicle access using RFID and IoT technology...

🔍 Project Overview

Each registered vehicle is equipped with an RFID tag...

💡 Key Features

  • Secure user registration and login
  • Live parking availability tracking
  • RFID-enabled gate access
  • Push notification alerts
  • Entry and exit logging with user roles
  • Data encryption and audit trail for security

🛠 Technologies Used

  • Frontend: Kotlin with Jetpack Compose
  • Backend: Firebase Authentication, Firestore
  • IoT: RFID Reader + Tag
